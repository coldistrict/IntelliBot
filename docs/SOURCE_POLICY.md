# Source Policy

- Official sources are the highest-trust evidence and should be prioritized first.
- Reputable news and premium news are secondary support layers.
- Manual Mode can also use live X intelligence through xAI search tools without direct X API integration.
- Official social accounts outrank high-trust domain experts, which outrank reporter social, which outrank generic social.
- Every trusted live social account shown in the UI must include an explicit trust reason and relevance reason.
- Generic social is narrative context, not primary evidence.
- Broad X consensus is used for narrative, uncertainty, confidence, and priced-in risk adjustments; it is not a standalone probability engine.
