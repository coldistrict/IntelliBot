# Prerequisites

## Required

- Python 3.12 via `uv`
- Node.js 22 with `pnpm`
- Docker Desktop
- Postgres via Docker Compose
- `OPENAI_API_KEY`
- `XAI_API_KEY`
- `TAVILY_API_KEY`

## Optional

- `FRED_API_KEY` for better macro/Fed analysis
- Premium news subscriptions and Playwright session state later

## Not Needed In v1

- Wallet credentials
- Trading keys
- X API access
